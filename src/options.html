設計上の扱い

この欄はプロトタイプ用です。正式運用では、教務側の正規データ/API/CSVを唯一の情報源として自動同期し、学生が二重管理しない構成に置き換えます。

形式は { "courses": [ ... ] }。同じ講義コード、または同じ科目名のデータを優先して置換します。まず「記入例を表示」を押すと、書き方がわかります。
