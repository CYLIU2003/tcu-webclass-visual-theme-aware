# 正式運用へのロードマップ

## 1. データ連携

プロトタイプは2026年度時間割PDFのスナップショットを同梱しています。正式版ではPDF抽出を廃止し、教務システムのAPIまたは正規CSVを唯一の情報源にします。

必要なキーは、講義コード、年度、学期、曜日・時限、教室ID、担当教員ID、クラス、キャンパス、履修者ID、変更履歴です。

## 2. WebClassとの結合

1. WebClassコースへ講義コードを属性として付与する。
2. ログインユーザーの履修科目を講義コードで取得する。
3. 時間割、教室マスタ、教員マスタをサーバー側で結合する。
4. 科目名照合は講義コードが欠落した場合のフォールバックに限定する。

## 3. 変更情報

休講、補講、教室変更、オンライン切替、担当変更を別テーブルで管理し、通常情報に上書きせず履歴として保持します。表示には更新時刻と情報源を必ず付けます。

## 4. 教室の利用者向け表示

`12K` などの教室コードを推測で変換せず、正式な教室マスタからキャンパス、建物、階、教室名、地図URL、バリアフリー経路を取得します。

## 5. セキュリティと権限

拡張機能はWebClassドメインだけを対象とし、成績、提出物、認証情報を外部送信しません。正式版でも最小権限、監査ログ、データ保持期間、学生・教員・管理者の権限分離を明示します。

## 6. 検証

- 講義コードの結合率
- 履修科目の表示漏れ率
- 教室・担当教員の一致率
- 同名科目の誤結合率
- 休講・変更情報の反映遅延
- スマートフォン・PC・アクセシビリティ検証

学内試行では、まず一部学科で正規データと突合し、誤結合がないことを確認してから対象を拡大します。
