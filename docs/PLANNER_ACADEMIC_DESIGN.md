# 履修台帳と進級・卒業確認

WebClassで表示中の年度・学期の参加コースを、プランナーを開いたとき自動表示する。分かる科目は週間時間割に置き、未照合のコースも別の行で表示する。手動追加と、取り込んだコースの除外・復元は端末に保存する。取り込む範囲を現在のタブの年度・学期に限定し、複数タブの場合は起点を選べるようにする。

過年度はWebClassで対象年度・全学期を表示して取り込む。過年度履修は履修台帳に蓄積する。成績と単位は成績表から科目単位で照合する。参加履歴、成績未確認、不合格、合格、認定を区別する。開講年度と講義コードが一意なら重複を防ぐ。同名や再履修の算入条件があいまいな場合は、本人が算入対象を確認する。

単位の確認で、入学年度・学科・課程とひらめき、教職、TAPの状況を使う。公開要覧の総単位条件を出典付きで確認する。必要な必修・区分別条件がそろう場合は個別に比較し、照合できない箇所を明記する。TAPの読み替え、教職、ひらめきの修了条件を卒業・進級の単位に自動加算しない。ポータル認定の単位を記録する。

成績はローカル処理のみ。本人の成績表の科目名・成績・単位を画面から保存する。WebClassの参加履歴から合否を推測しない。


## 設計レビューを反映した点

- Opusの設計をもとに、参加履歴、合否・認定、算入の確認を科目ごとに記録する。開講年度と講義コードが一致する成績は既存の記録を更新する。コードなしの場合、同じ年度に同名候補が複数あれば利用者に確認を求める。成績が変わった場合は算入・区分を再確認する。同名または同じコードの修得記録が複数算入されようとした場合は保留して通知する。
- 進級と卒業の算入を個別に確認する。標準の集計時点は3年次進級が入学翌年度末、4年次進級がその翌年度末。休学や留年などの場合は進級先ごとに集計年度を指定する。卒業要件は科目カードで確認済みの区分を集計する。旧版の単位メモは別の欄で開ける。
- Geminiのデザイン案をもとに、取込元、科目カード、進級・卒業の集計を分けて表示する。スマートフォン幅では1日ずつ表示し、曜日をタップして切り替える。
- 週間時間割の配置は確認済みの2026年度のカタログを使う。過年度の参加履歴は、WebClassで表示した年度ごとに履修台帳へ追加できる。公式の成績照会は[教学課の案内](https://www.asc.tcu.ac.jp/2445/)を参照。
