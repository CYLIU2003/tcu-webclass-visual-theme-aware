# 履修区分候補の試行データ

このデータは卒業・免許・プログラム修了の判定を行いません。入学年度と所属に一致する公式表の一部を目視転記した108行を保持し、開講科目との結合は科目名による未確認候補です。訂正表、代替科目、コース変更、選択グループの充足は未照合です。未収録は自由選択・不要を意味しません。

カードは「同名資料・要確認」のみを表示し、必修等を当該開講科目の確定区分として表示しません。詳細では原表上の区分を明示し、同一科目か未確認と伝えます。

| 区分 | 対象 | データ | 根拠 |
|---|---|---:|---|
| 学科 | 2026年度入学・情報工学部情報科学科、一般／国際コース | 60行 | 2026年度教育課程表PDF 4〜5ページの○印・△1〜3印。異なるコースで区分が違う科目は未掲載 |
| ひらめき | 2025年度入学・理工学部 | 4行 | 理工学部向けリーフレットPDF 2ページ、◎印 |
| ひらめき | 2025年度入学・建築都市デザイン、情報工、環境、メディア情報、都市生活、人間科学の6学部 | 12行 | 6学部向けリーフレットPDF 2ページ。必選の別は掲載されておらず、掲載候補としてのみ表示 |
| ひらめき | 2024年度入学・理工学部のひらめきプログラム | 4行 | 科目一覧の2024年度表画像、◎印 |
| ひらめき | 2023年度入学・理工学部6学科（自然科学科を除く）のひらめきプログラム | 4行 | 科目一覧の2023年度表画像、◎印 |
| ひらめき | 2022年度入学・理工学部の機械工学科・機械システム工学科・電気電子通信工学科 | 7行 | リーフレットPDF 4ページ、◎印。2024年度表と同名でも単位数が異なる |
| ひらめき | 2026年度入学・リーフレット掲載の7学部 | 8行 | 2026年度リーフレット2ページ。必選の別は掲載されておらず、掲載候補としてのみ表示 |
| 教職 | 2026年度の理工学部・情報工学部教職課程（画面は2026年度入学の情報科学科のみ選択可） | 9行 | 教職課程PDF 8ページ。「教育心理学」「発達心理学」は2科目から1科目必修。☆印の自由選択算入も候補表示 |

出典台帳 `data/curriculum-source-snapshots.json` は2022〜2026年度のひらめきリーフレット、2026年度の教育課程・教職資料と表画像のURL・SHA-256・サイズを記録します。保存した11資料すべてを候補行として抽出したわけではありません。`data/curriculum-candidates.json` の各候補は資料IDとページを持ち、状態は `visually-reviewed-source-unmatched-offering` です。学科の必修と、課外プログラム・教職の必修は別の要件です。

原本キャッシュは公開リポジトリや配布ZIPに入れず、ローカルの `data/source-cache/curriculum/` に保存します。取得元の資料が更新されていたら古いハッシュを上書きせず、別スナップショットとして再レビューします。

```powershell
python data/verify_curriculum_sources.py
# 保存ファイルがない場合だけ、台帳とハッシュが一致する原本を取得
python data/verify_curriculum_sources.py --fetch-missing
python data/build_curriculum_candidates.py --output data/curriculum-candidates-rebuilt.sqlite
node tests/test_curriculum_candidates.mjs
```

SQLite出力先は新規ファイルのみ。外部キー・一意制約・整合性チェックを実施し、失敗時には出力を残しません。既存の年度横断DBには自動統合しません。追加時には原本の対象年度・対象課程、記号の凡例、表の行と注記を視覚照合し、開講科目のコードとの対応、訂正表と複数人による確認が終わるまで候補のままにします。
