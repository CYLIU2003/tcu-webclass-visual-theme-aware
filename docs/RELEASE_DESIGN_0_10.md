# WebClass Visual v0.10.0 設計書

## 学生が確認する順番

| 場面 | 画面に出す情報 | 次にできること |
| --- | --- | --- |
| コース一覧を開く | 開講年度、現在の学期、参加件数、授業データとの一致件数、要確認件数 | 履修・進級チェックで科目を確認 |
| 要確認の科目がある | WebClassに表示された科目名、講義コードの候補、担当、時限・学期 | 科目を選択するか、大学の資料で確認 |
| 登録科目の単位を調べる | 公式シラバスの単位数と出典、照会中・未確認・照会失敗の状態 | 算入対象と確認した場合に見込みへ反映 |
| 進級条件を確認する | 入学年度・学科・進級先、学修要覧の原表、取得済みと見込みの単位数、入力が残っている件数 | 総単位数と必修・区分別条件を大学資料と照合 |
| 過年度・卒業要件を調べる | 2022〜2026年度入学の学科別要覧、出典付きの過年度授業候補 | 原表を開き、該当科目・課程・適用条件を確認 |

## 照合と単位の扱い

- 画面に表示されたWebClassの参加コースを読み込む。読込元の年度・学期を画面に表示する。年度・学期を切り替えた場合はWebClassのコース一覧から開き直し、新しい表示範囲を使う。作業中の入力を自動で置き換えない。
- 開講年度と講義コードを照合する。コードなしの場合は授業名・担当・曜日時限を照合し、学期が判別できれば加味する。複数の候補が残るときは選択肢を示す。
- WebClassから取り込む項目は表示中の年度・学期・講義コード・科目名。公開シラバスへの照会には許可を取得し、開講年度・講義コード・学期を送る。
- シラバスから得た単位数は科目情報として表示する。進級の見込みに加える際は、算入対象か学生が要覧で確認する。時間割プランナーに保存した予定単位数も同じ扱いにする。
- 学修要覧で確認できる進級先別の総単位条件を、出典ページとともに表示する。取得済み単位数は大学ポータルで確認した値を入力する。必修、区分別条件、個別の認定と正誤表は大学資料から確認する。

## 正式版の受け入れ条件

1. コース一覧の操作から、表示中の全科目の内訳と確認が必要な科目に到達できる。複数のWebClass一覧が開いているときは起点を選べる。
2. 同名・別コード、同名・別学期、同じコースの重複表示を区別する。候補を変更した場合に合計と未入力件数が更新される。
3. シラバスの許可を拒否した場合や照会が失敗した場合も、科目一覧と手入力を使える。保存済みの予定単位は学生が進級への算入を明示した後に合計へ入る。
4. キーボードで操作でき、360px幅で履修画面の主要ラベルと入力欄が収まる。実際のWebClassで参加コースと教材を確認し、学生情報を含まない画面で相互レビューする。
5. 配布ZIPを展開してインストールし、同梱ガイドから初回操作を完了できる。公開要覧の収録範囲と年度横断データの監査状況は公開ノートに記載する。

## チームの進め方

- GPTが仕様と受け入れ条件を決め、実装の統合と公開の可否を判断する。
- Opusが画面の流れ・文言・初回導入を担当する。Geminiが照合・単位計算と回帰テストを担当する。担当ごとに作業フォルダを分ける。
- レビューでは匿名化した画面と公開資料を使う。大学アカウントの操作と実画面の検証は管理側で行う。
